# 操作系统·计算机组成原理

## 计组·CPU相关

### CPU由哪些部分组成?

1. 控制单元CU(ControlUnit)
2. 算数逻辑单元ALU(Arithmetic Logic Unit)
3. 寄存器Register, 常见寄存器有程序计数器PC(ProgramCounter), 指令寄存器IR(InstructionResgister)
4. 缓存Cache
5. 时钟电路Clock
(?)可能控制单元, 算逻单元和寄存器问得比较多

## 操作系统

### 操作系统的作用

1. 硬件管理
2. 进程(软件)管理
3. 文件管理
4. 内存管理
5. 系统安全保护
6. 系统服务和软件支持
7. 用户接口

## 关于进程·线程

### 定义和区别

* **进程**是操作系统资源分配和调度的基本单位。
* **线程**CPU调度的基本单位

### 进程有哪些状态?

启动, 运行, 阻塞, 就绪, 结束

## 进程间通信 IPC (Inter-Process Communication)

### 概括地说, 进程间通信有哪些方法?

* 管道(依赖系统调用, 间接共享操作系统内核中的一块缓冲区, 半双工)
* 信号(Signal)
* 信号量 (Semaphore) 关键字: P操作和V操作
* 消息队列
* 共享内存
* 套接字Socket

## 进程间调度·切换

### 常见的调度算法有哪些?

1. 先来先服务
2. 短任务优先
3. 最短完成时间优先
4. 时间片轮转(这个算抢占式)
5. 最高优先级调度(会提前为每个进程分配优先级)
6. 多级队列调度->多级反馈队列调度(进程可以在队列之间移动)

* 这几种算法可以按照是否有优先级(时间片轮转/其他的一些有优先级), 或者是按抢占式/非抢占式分类.
* 短任务优先和最短完成时间优先的区别是抢占式/非抢占式.

### 上下文切换的过程是什么样的?

* 上下文切换是指保存当前进程的状态(如寄存器, 程序计数器,内存映射等), 然后恢复另一个进程的状态.
* 切换的触发: 硬件终端, 异常, (进程请求)系统调用

1. 将旧进程的CPU寄存器状态保存至进程控制块PCB
2. 修改旧进程的PCB的进程状态(运行态->就绪态/阻塞态)
3. 根据调度算法选择下一个要运行的新进程
4. 从新进程的PCB中恢复寄存器快照至CPU
5. 修改新进程的PCB的进程状态为运行态

### 哪些情况下会导致内核态和用户态的切换?

1. 中断: 一个由硬件或软件产生的信号, 它通知CPU需要立即暂停当前正在执行的任务(硬件中断或软件中断)
2. 异常: 当CPU在执行用户态程序的指令时，检测到了一个错误或特殊条件(除零错误, 缺页, 调试断点)
3. 系统调用: 应用程序主动请求操作系统内核为其提供服务(创建进程, 读写文件, 申请内存, 网络通信)

#### 名词解释

* 内核态: 操作系统内核运行的状态, 可以执行所有指令, 访问所有硬件资源和内存.
* 用户态: 普通应用程序运行的状态, 权限受限, 如果想要主动访问系统资源需要通过系统调用.
* 硬件中断: 外部硬件设备主动发出的中断信号, 比如时钟中断, I/O中断, 外部输入中断
* 软件中断: 由程序主动触发的中断, 比如系统调用中断, 异常
