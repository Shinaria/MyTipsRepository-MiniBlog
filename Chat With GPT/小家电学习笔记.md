# 小家电学习笔记

## 厨房小家电

### 分类

1. 电饭煲
2. 破壁机
3. 空气炸锅
4. 电压力锅
5. 咖啡机
6. 电水壶

### 产品组成结构

1. 加热系统(电水壶:发热盘,空气炸锅:PTC陶瓷,高端电饭煲:IH线圈): 加热慢, 局部过热, 异味
2. 容器/内胆: 粘锅, 生锈, 有塑料味
3. 控制系统(机械旋钮, 微电脑程序): 按键失灵, 程序错乱
4. 安全保护模块(遥控器,干烧开关,蒸汽感应,开盖断电):自动断电异常,无法启动
5. 电源与底座(分体式设置): 底座进水,接触不良

### 关键技术参数

1. 额定功率: 最大功率>1500w的建议单独插座
2. 容量: 1人推荐1L,3人推荐1.7L
3. 温控精度: 高端±1℃,普通±5℃
4. 转速:≥22000RPM可称"破壁", 壁->细胞壁

### 家电清洁保养原则

1. 清洁,加水,拆卸前断电, 勿湿手操作, 勿通电时清洗.
2. 及时清洁, 防止干结食物残渣, 糖, 油, 淀粉类残留.
3. 分区清洁: 内胆, 杯体, 炸篮可水洗;主机, 电路, 面板不可水洗.
4. 定期除垢: 涉水加热产品每月使用白醋或专用除垢剂除水垢.
5. 彻底晾干: 清洁后所有部件需完全晾干, 然后才可收纳或组装, 防止霉变和短路.
6. 正确使用: 不超量, 不空烧, 不处理非指定食材, 避免电机过载或者损坏.
7. 更换耗材: 密封圈, 滤网, 刀头等损耗件出现老化,异味或者性能下降时需及时更换.

### 使用禁忌和风险提示

1. 严禁干烧: 无水状态下通电会烧毁加热盘, 甚至引发火灾.
2. 勿超最大刻度线: 沸腾溢出可能会发生家电短路或者烫伤.
3. 微波类勿放入金属器皿, 会产生电弧, 损坏机器.
4. 勿用钢丝球刷内胆, 会破坏涂层, 减少寿命.
5. 首次正式使用前先清洗和"空"运行一次, 去除生产残留.
